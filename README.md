## `> whoami`

I'm Aki, an IT student and full-stack developer who likes figuring out how things work by building them.

My work spans web and mobile development, backend systems, UI/UX, and increasingly, connected health technologies. I've worked on everything from patient and appointment platforms to administrative dashboards, interactive web applications, and smartwatch-assisted health monitoring systems that connect wearable sensors, mobile devices, APIs, and databases.

I like projects where I can think beyond a single screen or feature and understand how the entire system fits together — from the interface someone interacts with to the data, logic, and infrastructure working underneath it.

I'm especially drawn to problems that push me into unfamiliar territory.
